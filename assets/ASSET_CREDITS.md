# City Moon asset pack

These vector assets were created specifically for **The City That Forgot the Moon** project and are stored locally so the game can use them offline.

- `city-skyline.svg` — original moonlit city backdrop illustration.
- `moon-fragment.svg` — original collectible icon.
- `lantern.svg` — original cyan lantern icon.
- `logo.svg` — project logo.

These newly created project assets may be used and modified within this game repository. No external asset downloads or network requests are required at runtime. The current 3D scene is still procedurally built from low-poly blocks; these SVGs add original visual assets to the interface and chapter presentation, not rigged 3D models.
