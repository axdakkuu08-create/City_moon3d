# The City That Forgot the Moon — 3D Android build

This repository contains a GitHub Actions workflow that generates the Android WebView project and builds a debug APK. Open **Actions** to monitor `Build City Moon 3D APK`. On success, download the `city-moon-3d-debug-apk` artifact.

Note: the workflow currently generates a lightweight WebGL prototype as part of the build; it does not import the full project ZIP automatically.
